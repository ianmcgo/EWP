# Epic Warpath Army Builder

A fast, mobile-friendly army list builder for **Epic Warpath** (Mantic Games), in a single `index.html`.

**Features**
- All 8 factions, 165 units, with FAQ & Errata v1.2 applied (changed units are marked)
- Live company slot tracking: units you can't take yet are greyed out with the reason
- Plain-English validation, points bar, Unique `[U]` checks, Command Transports
- Battlefield Stratagems, Army Special Rule, Strategic Orders, and tap-to-read keyword rules
- Model photos for most units
- Unlimited lists saved in your browser; share links, text export, JSON import/export, and a printable roster with every rule your list needs
- Dice roller: D8 attacks with Exploding 8s, Command Dice with re-rolls and a CP tracker, and the Targeting Die

To use it, open `index.html`, or enable GitHub Pages on this repo.

See [design.md](design.md) for how it works and how to rebuild the data.
